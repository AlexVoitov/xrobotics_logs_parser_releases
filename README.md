# XRobotics Logs Parser releases

Public download page and binary releases for XRobotics Logs Parser.

This repository does not contain the application source code, machine logs,
configuration caches, or credentials. The download page always points to the
assets attached to the latest published GitHub Release.

## Stable download links

- Windows x64: `XRoboticsLogsParser-windows-x64.zip`
- Linux x64: `XRoboticsLogsParser-linux-x64.tar.gz`

Open the GitHub Pages site to detect the operating system and start the matching
download automatically.
